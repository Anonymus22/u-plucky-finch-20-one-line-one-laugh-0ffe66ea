# One Line, One Laugh

A tiny, deterministic Node 22 program that writes exactly one funny line (1–200 characters) to `entry.txt`.

## Run

```sh
node main.ts
```

This writes the one-liner to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if that variable is not set).
